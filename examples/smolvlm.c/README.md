# SmolVLM-256M-Instruct Inference

**简体中文：** [readme_cn.md](readme_cn.md) · **English:** [readme_en.md](readme_en.md)

This repository contains the SmolVLM application and a reusable inference
runtime. The model-independent runtime is maintained as a standalone project
in [`inference_sdk/`](inference_sdk/README.md).

本仓库包含 SmolVLM 应用和可复用推理运行时。与模型无关的通用运行时已
整理为独立工程，详见 [`inference_sdk/`](inference_sdk/README.md)。
